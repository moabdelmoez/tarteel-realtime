# Issue tracker: GitHub

Issues and PRDs for this repo live in GitHub Issues for `moabdelmoez/tarteel-realtime`. Use the `gh` CLI for issue operations.

## Conventions

- Create an issue: `gh issue create --repo moabdelmoez/tarteel-realtime --title "..." --body "..."`
- Read an issue: `gh issue view <number> --repo moabdelmoez/tarteel-realtime --comments`
- List issues: `gh issue list --repo moabdelmoez/tarteel-realtime --state open`
- Comment: `gh issue comment <number> --repo moabdelmoez/tarteel-realtime --body "..."`
- Apply labels: `gh issue edit <number> --repo moabdelmoez/tarteel-realtime --add-label "..."`
- Close: `gh issue close <number> --repo moabdelmoez/tarteel-realtime --comment "..."`

When a skill says "publish to the issue tracker", create a GitHub issue.
